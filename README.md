## 무엇을 하나

매일 갱신되는 한국 입법·사법 동향을 한 화면에서 — [**법률 데일리**](https://oracle.vnods.com/law-daily.html)

- **📈 트렌드 차트** — 법령/판례/의안/인용 신규 추이 (14·30·90·180일, 이동평균)
- **🗂️ 날짜별 카드** — 신규/변경 법령, 신규 판례, 신규 의안, FSC 결정
- **🔗 인용 그래프** — 많이 인용된 법령·선례와 조문 단위 연결
- **🤖 AI 분석** — 일일 종합(입법 방향·주목 의안·분야 추세) + 항목별 분석
- **🧑‍⚖️ 입안자 매칭** — 의안 발의자를 선거 당선자 정보와 매칭. "이 법, 누가 냈나" + 최근 7일 대표발의 현황

개발자용 **REST API**와 **MCP 서버**도 제공합니다 → [API 문서](https://oracle.vnods.com/docs.html)
